# Phase 01 migration fixture

`Phase01.store` was generated by the unchanged Phase 01 model and persistence source, before Phase 02 was implemented. The writer used module name `Selno` and the original V1 migration plan. Its WAL was empty after the writer exited; only the checkpointed SQLite file is included.

It contains one completed task, one project, one completed step, five default categories and the seeding marker. The task's deterministic UUID is `02000000-0000-0000-0000-000000000002`; timestamps use `1790000000` seconds since 1970.

The file is 102,400 bytes, SHA-256 `5b0c1e439cc01eaa1bcecb166590e18babbc8c7bf13e094716c9ba862d8b562e`. `Phase01Fixture.swift` embeds a Foundation zlib-compressed copy of these exact bytes. It decompresses and checks both length and SHA-256 before writing a temporary store. This avoids requesting Desktop access from the sandboxed test host when Xcode places the test bundle outside the app bundle. The original file is retained for inspection; migration tests never modify it.
